# PwnZ Network
Blue-and-green gaming-themed teaser page for **PwnZ.live**, within the broader Light of Hope ecosystem.

This is a single-file static site. The homepage is `index.html`; no build tool, framework, tokens, or Firebase keys are required.

## Publish with Vercel

1. Go to https://vercel.com/new and import GitHub repository **NickPwnZLegit/PwnZ-Network**.
2. In Project Settings / Build & Development Settings, use **Framework: Other** and **no build command**. The site lives at the repository root.
3. Deploy and open the generated `*.vercel.app` URL to test it.
4. In Vercel Project → Settings → Domains, add **pwnz.live** and, optionally, **www.pwnz.live**.
5. At the domain registrar or DNS host, set the **exact A or CNAME values Vercel shows for your project**. Do not guess or switch nameservers without checking your existing mail/DNS services.
6. Set your preferred canonical hostname in the Vercel project and wait for domain validation/HTTPS.
7. Test HTTPS and both hostnames from an incognito browser. The repo being public does **not** automatically deploy it.

If Vercel's GitHub import isn't connected, authorize the GitHub repository first. For safe future edits, merge only reviewed commits to `main`.

## Status and scope

- The owned domain **PwnZ.live** and already-created **PwnZ token** are referenced as future integration plans; nothing is minted or staked here.
- Gaming, creator spaces, NFTs and staking are **planned features**, not live services.
- The proposed **Light of Hope Blockchain** will be shared infrastructure for the Light of Hope, EdenNetwork, PwnZ Network and EnderNet platforms, pending technical and legal work.
- No payment or wallet collection is present on this page.

Edit `index.html`. Vercel redeploys changes after import when linked to the GitHub `main` branch.
